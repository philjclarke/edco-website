# Publishing

Content is edited and published in **Prismic**: https://66bbee42.prismic.io

The editor guide (fields, page sections, previews, publishing, what to ask the
web team for) is at https://claude.ai/artifact/CQ92WZ2jERv9PMoxJUya5Y.

Publishing in Prismic rebuilds the site through a Vercel deploy hook; changes
appear a few minutes later. Technical details are in the README under *Prismic*.

The earlier Google Sheet copy deck and `/admin` publish console were retired on
26 October 2026 and are in git history.
